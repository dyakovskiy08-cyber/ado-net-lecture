# Отчёт по практике ADO.NET + PostgreSQL

**Репозиторий:** https://github.com/dyakovskiy08-cyber/ado-net-lecture  
**Технологии:** C# / .NET 10, Npgsql, PostgreSQL 17.

## Что входит в практику

1. Подключение к PostgreSQL и получение версии сервера.
2. Создание и удаление таблиц `groups`, `students`, `grades`.
3. Добавление одной и нескольких записей, использование параметров и `RETURNING id`.
4. Заполнение учебной базы: 3 группы, 8 студентов, 16 оценок.
5. Изменение и удаление записей (`UPDATE`, `DELETE`).
6. Чтение данных через `ExecuteScalar`, `ExecuteReader`, обработка `NULL`.
7. Фильтрация, сортировка, ограничение выборки, `JOIN`, `GROUP BY`, `HAVING`.
8. Демонстрация SQL-инъекции и защита параметризованными запросами.
9. Транзакции: удаление оценок и студента, `COMMIT` и `ROLLBACK`.
10. Консольное приложение «Студенты».

## Контрольные результаты учебной базы

После шага заполнения базы ожидается:

| Проверка | Ожидаемый результат |
|---|---:|
| `SELECT COUNT(*) FROM groups` | 3 |
| `SELECT COUNT(*) FROM students` | 8 |
| `SELECT COUNT(*) FROM grades` | 16 |

Другие контрольные результаты и фрагменты кода приведены в [PRACTICE.md](PRACTICE.md).

## Статус выполнения

**Важно:** этот файл фиксирует структуру отчёта и контрольные ожидаемые значения из инструкции. Запуск C# программы и SQL-запросов в Codespace в рамках подготовки этого коммита не выполнялся. Поэтому фактические выводы терминала и результат `check.sh` здесь не заявляются.

Для получения фактического результата:

1. Откройте Codespace этого репозитория.
2. Выполните шаги из [PRACTICE.md](PRACTICE.md) по порядку.
3. Запустите проверку из корня репозитория: `bash check.sh`.
4. Сохраните созданный проверкой `RESULT.md` и приложите скриншоты вывода программы, если их требует преподаватель.
